23:58 Fix broken chatbot: escape unescaped apostrophes in KB strings (all pages) Fix
Problem

Broken chatbot needed correcting.

How it was fixed
  • The chatbot button did nothing because the chatbot <script> block had a JS syntax error: single-quoted knowledge-base strings contained raw apostrophes (We're, Malaysia's, it's, minutes' walk, We've, We'd). Earlier scripts (openDish, filters) were in separate blocks so they kept working, which masked the cause.
  • Escaped all 8 affected strings (verified each page's chatbot block now passes 'node --check'). Verified live: button opens/closes the panel, greeting + suggestions render, and questions return KB answers with contextual action buttons.
